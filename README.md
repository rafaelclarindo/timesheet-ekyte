# timesheet-ekyte

Skill para sincronizar as tasks da Thainá Gomes no Ekyte com a planilha de timesheet: uma aba nova por dia, links atualizados a cada 2 horas, e lançamento só quando pedirem para subir o timesheet.

Instruções do agente: [SKILL.md](SKILL.md). Contrato da API: [reference.md](reference.md).

Login, senha e token do MCP ficam só no `.env` local. Não vão neste repositório.
